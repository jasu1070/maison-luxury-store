# Maison — Curated Luxury Store

A premium e-commerce experience built for those who appreciate extraordinary craft and enduring quality.

[Live Demonstration](https://jasu1070.github.io/maison-luxury-store/)

---

## ✦ Features

- **Immersive Brand Experience**: Minimalist, high-aesthetic design with custom cursor interactions and smooth transitions.
- **Curated Collections**: Specialized filtering for Electronics, Fashion, Home, and Accessories.
- **Editorial Content**: Integrated 'Atelier' and 'Journal' pages for brand storytelling and editorial insights.
- **Seamless Shopping**: Instant 'Add to Bag' from any view, real-time cart drawer, and optimized order summary.
- **Global Search**: High-performance search modal accessible via `Ctrl + K`.
- **Responsive & Accessible**: Fully optimized for mobile and desktop, including semantic HTML and ARIA roles.

## ✦ Tech Stack

- **Frontend**: React 18
- **Styling**: Vanilla CSS (Custom tokens, Glassmorphism, CSS Variables)
- **Deployment**: GitHub Pages
- **Asset Management**: Google Fonts (Inter, Outfit), Lucide-inspired SVG iconography.

## ✦ Project Structure

```text
src/
├── components/   # Reusable UI elements (Navbar, Footer, CartDrawer, etc.)
├── pages/        # Main screens (Home, Shop, Atelier, Journal, Legal, etc.)
├── styles/       # Design system (global.css, layout.css, components.css)
├── data.js       # Centralized product and category metadata
└── App.js        # Core routing and state management
```

## ✦ Getting Started

### Prerequisites

- Node.js (v16+)
- npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/jasu1070/maison-luxury-store.git
   ```
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```

### Deployment

To deploy a new version to GitHub Pages:
```bash
npm run deploy
```
